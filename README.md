# 更好的帮助

自动扫描 AstrBot 已装插件的全部指令，在 WebUI 插件页里可视化排版，聊天中发送指令即可得到一张帮助图。

## 功能

- **自动扫描**：读取 AstrBot 指令注册表，按插件分组列出指令名、别名、说明与所需权限，无需手工维护。
- **可视化排版**：左栏分「内容调整 / 画布调整」两个页签，支持搜索、勾选、拖拽排序；右栏实时预览，两栏可一键左右互换。
- **本地合成**：帮助图由插件自己用 Pillow 绘制，不依赖 AstrBot 的 HTML 转图服务，也不会发起任何网络请求。
- **分组标题栏可关**：画布调整页签里关掉「显示分组标题栏」后，所有条目连排成一组，不再渲染分组标题条。
- **AI 文案**：选中条目后可一键「AI 翻译为中文」或「AI 润色」，把英文说明统一成通顺中文。
- **未注册功能挖掘**：独立的挖掘页面会整段扫描源码，把兜底 handler（如 `@filter.regex('.*', priority=1)`）里的每个 `if` 分支拆成候选，命中注释与字符串字面量作为触发词线索；守卫分支（权限、空值、提前 return）会被剔除，分支按「像不像真实触发词」排序，候选交给 AI 分批归纳。结果记在本页，可随时「再次查找」。
- **非指令功能**：源码里没有触发词的功能可标为「非指令」，帮助图里整条命令都不带斜杠，默认不勾选、不纳入；默认不追加标注，需要时在「编辑」里逐条填。
- **逐条标注**：指令与非指令都能在「编辑」里给单条加一段标注（例如 `[非指令]`、`[在售]`），留空表示这条不标注；非指令条目没单独设过时用默认标注（外观参数 `feature_mark`，默认留空即不追加）。
- **多触发词写法**：一个条目的主指令与别名在帮助图里各自带斜杠、用 `、` 连接，例如 `/塔罗、/tarot、/塔罗牌`；「非指令」类型则整条去掉斜杠，写成 `塔罗、tarot、塔罗牌`。
- **自定义条目**：可新增不属于任何插件的条目（分组、指令、注释、权限均可自定），也可随时编辑或彻底删除。「指令」框里直接写 `签到/打卡` 会自动拆成主指令 `签到` + 别名 `打卡`。
- **插件黑名单**：名单内的插件既不参与帮助图扫描，也不参与 AI 挖掘，默认排除本插件与 AstrBot 内置插件。
- **接管内置 `/help`**：AstrBot 自带的 `/help`（输出本体版本 + WebUI 版本 + 内置指令清单）会被直接禁用，`/help`、`/帮助`、`/菜单` 全部由本插件响应；禁用或卸载本插件时自动恢复原状。
- **内置指令进帮助图**：AstrBot 自带指令统一归到「AstrBot 内置」分组，和普通插件指令一起排进帮助图；`/help` 自己除外（列进帮助会自相矛盾）。即使黑名单里还留着 `builtin_commands`，开启该功能后也照样展示。
- **版本行**：标题下方显示 `AstrBot v本体版本 · WebUI v前端版本`；读不到 WebUI 版本（前端资源未下载）时只显示本体版本，可在「画布调整 → 标题区」里关掉或改字号、颜色。
- **权限过滤**：普通用户看不到管理员专用指令，判定规则与 AstrBot 指令权限完全一致。

下载zip安装，或者直接商店选择安装

## 使用

### 聊天指令

| 指令 | 说明 |
| --- | --- |
| `帮助` | 输出全部帮助图 |
| `帮助 原神` | 只输出与「原神」相关的条目 |
| `help` / `菜单` | `帮助` 的别名，可在配置中修改 |

`/help` 原先由 AstrBot 内置指令响应（输出本体版本、WebUI 版本与内置指令清单），装上本插件后这条指令被接管：内置 `/help` 会被直接禁用，发 `/help` 得到的是本插件的帮助图，而它原本提供的信息被拆成两处——版本号做成帮助图的版本行，内置指令清单以「AstrBot 内置」分组进图。

帮助图合成失败时（例如字体缺失）会自动降级为纯文本输出，不会丢消息。

### 插件页

打开 WebUI，进入「更好的帮助」插件详情页，打开其中的 Page；或直接访问：

```text
http://localhost:6185/#/plugin-page/astrbot_plugin_help_page/help
```

页面分成左右两栏，左栏顶部是「内容调整 / 画布调整」两个页签，右栏是实时预览；点右上的「⇄ 左右互换」可以把两栏对调，习惯预览在左的人也能顺手用。

**左栏 · 内容调整**

- 顶部搜索框按指令名、别名、分组名、插件名、说明实时筛选。
- 勾选条目后，用「AI 翻译为中文」把英文说明译成中文，或用「AI 润色」优化现有中文；分组标题上的「全选」可一次勾中整组。
- 「AI 挖掘未注册功能」打开独立的挖掘页面：顶部按钮用于「开始查找 / 再次查找」，页面记录上次扫到的候选与扫描时间，关掉窗口也不会丢。
- 每条候选右侧有「加入 / 废弃」：改好触发词点「加入」立刻成为自定义条目，点「废弃」直接把这一条丢进废弃堆，不影响其他候选；顶部「全部废弃」一次清掉当前整批。
- 底部「加入所选条目」按勾选批量处理：勾选的加入，**未勾选的进「废弃堆」，下次挖掘不再重复出现**。废弃堆里可以「恢复为候选」「移出废弃堆」，也能一键「清空废弃堆」让它们下次重新出现。
- 「＋ 新增条目」添加自定义条目；「不展示的条目」里是被隐藏的条目，可以编辑、恢复，自定义条目还能彻底删除。
- 条目行右侧常显「编辑 / 隐藏」，自定义条目额外有「删除」。
- 「编辑」里可以改**指令、分组、注释、类型、标注**。自动扫描来的条目改这些只影响帮助图与预览，不会改动插件本身；指令框里只留主指令就等于清空别名。
- 「指令」框支持写多个触发词（用 `/`、空格、逗号、顿号分隔），第一个作主指令，其余自动并入别名；别名没有单独的输入框，统一写在这里。
- 「标注」是**逐条设置**的，指令与非指令都能用：预填的就是这条当前生效的文字，留空表示这条不标注；切换「类型」时，只要没手动改过，标注框会跟着换成新类型的默认值。
- 分组标题右侧可直接填写分组说明，该说明会显示在帮助图的标题条上。
- 直接拖动条目可调整顺序，拖到别的分组上可改归属；拖动分组标题左侧的 `⋮⋮` 可整体移动分组。

**左栏 · 画布调整**

- 页签顶部直接填「名字」（主标题）和「副标题」；副标题留空则回落到自动统计的条数文案。
- 清单标题与组数跟页签挤在同一行，省下一整行竖直空间。
- 参数面板最上方是「配色方案」：晴空 / 夜幕 / 森屿 / 纸页 / 樱雾 五套成套配色，点一张整张图一起换；点击已选中的方案等同重新套用，会清掉逐个改过的颜色。
- 往下的分区按「画布与留白 / 背景 / 标题区 / 分组标题条 / 卡片 / 指令文字 / 页脚 / 字体」排列，逐项调数值与颜色；标题区只留字号与颜色，主标题与副标题已挪到页签顶部。
- 颜色按四层组织：背景（渐变两端）、表面（卡片底色 / 描边 / 阴影）、文字（标题 > 指令 > 说明，另有副标题、分组说明、页脚、版本行等弱化文字）、强调（斜杠与分组色条）。改主色时按层改，比逐项试色一致得多。
- 关掉「显示分组标题栏」即可让所有条目连排成一组，只保留卡片网格。

编辑完成后点右上角「保存」写入磁盘；「恢复默认」会清空全部手动配置（需连点两次确认）。

## 配置项

| 配置 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `commands` | list | `["帮助", "help", "菜单"]` | 指令触发词，第一项为主名，其余为别名，修改后需重载插件 |
| `filter_by_permission` | bool | `true` | 按发送者权限过滤管理员专用指令 |
| `block_builtin_help` | bool | `true` | 屏蔽 AstrBot 自带的 `/help`；开启后 `/help` 完全由本插件接管，内置 help 指令被直接禁用，禁用/卸载插件时自动恢复 |
| `show_builtin_commands` | bool | `true` | 把 AstrBot 内置指令纳入帮助，统一归到「AstrBot 内置」分组；会覆盖 `ignored_plugins` 里的 `builtin_commands`，内置 `/help` 本身始终不列出 |
| `show_version` | bool | `true` | 帮助图标题下方显示版本行（AstrBot 本体版本 + WebUI 版本），插件页「标题区」里还能改字号与颜色 |
| `ignored_plugins` | list | `["astrbot_plugin_help_page", "astrbot", "builtin_commands"]` | 插件黑名单，名单内的插件既不扫描也不挖掘；想让某个内置插件出现在帮助里，把它从名单中删掉。注意 `show_builtin_commands` 开启时 `builtin_commands` 会被覆盖 |
| `font_path` | string | 空 | 帮助图字体文件路径，留空用插件内置的荆南圆体，再回退系统字体 |
| `image_title` | string | `功能帮助` | 帮助图默认标题，插件页未单独设置时使用 |
| `image_footer` | string | 空 | 帮助图默认页脚，留空不显示 |
| `ai_provider` | string | 空 | AI 文案用的模型 Provider ID，留空使用当前默认对话模型 |

### 关于字体

`font_path` 填字体文件路径（不是 CSS 字体名），例如 `C:/Windows/Fonts/msyh.ttc`。留空时按「插件内置荆南圆体 → 系统常见中文字体」的顺序查找；一个都找不到才会回退到 Pillow 内置位图字体，此时中文会显示成方框。插件页参数面板的「字体」分区也能单独设置，并会显示当前实际生效的字体来源。

## 数据位置

手动配置按「文本内容 / 画布内容 / 挖掘记录」拆成三个文件，存放在 `data/plugin_data/astrbot_plugin_help_page/`：

| 文件 | 内容 |
| --- | --- |
| `help_content.json` | 条目、分组、隐藏、覆写、手动排序（对应「内容调整」页签） |
| `help_canvas.json` | 外观参数与页面界面偏好（对应「画布调整」页签） |
| `help_mining.json` | AI 挖掘结果、废弃堆与上次扫描摘要 |

`help_content.json` 示例：

```json
{
  "hidden": ["被隐藏条目的 handler_full_name"],
  "overrides": {
    "handler_full_name": {
      "command": "显示名",
      "aliases": ["别名一", "别名二"],
      "description": "说明",
      "group": "分组",
      "kind": "feature",
      "mark": "[非指令]"
    }
  },
  "custom": [
    {
      "id": "c1a2b3c4",
      "group": "娱乐",
      "command": "签到",
      "aliases": ["打卡"],
      "description": "每日签到",
      "permission": "everyone",
      "kind": "command"
    }
  ],
  "groups": {"娱乐": {"description": "休闲玩法", "order": 2}},
  "order": ["handler_full_name", "c1a2b3c4"]
}
```

- `order` 是条目的全局显示顺序，`groups` 里的 `order` 由条目顺序推导。
- `overrides` 里的字段都只影响帮助图与预览，不改动插件本身；`aliases` 写成 `[]` 是有效覆写（清空别名），不写该键则沿用扫描到的别名。
- `kind` 为 `feature` 表示「非指令功能」：帮助图里整条命令不带斜杠，并在后面追加这条自己的标注。
- `mark` 是**逐条设置**的标注，指令与非指令都能用：写了就追加在标题行末尾，写 `""` 表示这条不标注，整个键不写时非指令条目回落到默认标注（外观参数 `feature_mark`，默认留空）、指令条目则不带标注。图片与纯文本降级输出都会跟着这条走。
- 渲染时主指令与别名会合并成一批触发词，各自带斜杠、用 `、` 连接（忽略大小写去重），例：`/塔罗、/tarot、/塔罗牌`。
- `appearance` 只保存你在插件页显式改过的外观项，未出现的项回落到配置项默认值。
- 旧版单文件 `help_data.json` 会在三个新文件都不存在时自动迁移一次，原文件保留为备份，之后不再参与读写。

删掉这三个文件等同于「恢复默认」。

## 说明

- 帮助内容只影响展示，不会改动其他插件注册的指令本身；条目的「指令」字段默认填入扫描到的实际指令，改它只改帮助图上的显示名。
- 自动扫描结果来自 AstrBot 的指令注册表，因此新装插件后打开插件页或重新发送帮助指令即可看到。
- 「AI 挖掘未注册功能」只做静态源码扫描，结果需要人工确认才会写入帮助；单条可「加入」或「废弃」，废弃的进废弃堆、下次挖掘不再出现。
- 挖掘分两段：先静态拆分支（剔除权限/空值/提前 return 这类守卫，按字面量与注释排序），再交给 AI 分批归纳触发词。AI 某批没给出结果时，该批会用源码字面量兜成「存疑」候选，不会整条消失；若模型完全不可用则会报错并保留上次的结果。
- 挖掘结果、废弃堆与上次扫描摘要都会立即落盘，关闭页面或重载插件都不会丢。
- 此工具是作者使用ai进行制作
